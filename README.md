# إدارة البرج — النسخة الكاملة 2.0

هذه نسخة جديدة ونظيفة، ومصممة للعمل على الهاتف والكمبيوتر عبر GitHub Pages.

المميزات:
- إضافة وتعديل وحذف المشتركين.
- اسم، رقم هاتف، حساب، باقة، مبلغ، تاريخ انتهاء.
- تسجيل التسديد وإلغاؤه.
- حالات: مسدّد، غير مسدّد، قريب الانتهاء، منتهي.
- لوحة إحصائيات.
- بحث وتصفية حسب الحالة.
- زر واتساب برسالة تنبيه جاهزة.
- إنشاء إيصال تسديد وطباعته أو حفظه PDF.
- نسخ احتياطي JSON واسترجاعه.
- حفظ البيانات على نفس الجهاز عبر LocalStorage.

مهم:
هذه النسخة لا تزال نسخة تجريبية محلية. البيانات ليست قاعدة بيانات مركزية بعد.
المرحلة التالية يمكن أن تكون قاعدة بيانات حقيقية + حساب مدير + SMS/WhatsApp آلي.
